# 🎬 Movie Recommendation System

A machine learning-based Movie Recommendation System that suggests similar movies based on user input using content-based filtering techniques.

---

## 🚀 Project Overview

This project recommends movies similar to a selected movie using similarity scores calculated from movie features. It uses machine learning and data processing techniques to build an efficient recommendation engine.

---

## 🧠 How It Works

- Data preprocessing and feature extraction
- Vectorization of movie features
- Similarity calculation using cosine similarity
- Recommendation of top similar movies

---

## 🛠️ Tech Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- Jupyter Notebook
